# Betterment Improvements for RDR2
![Language](https://img.shields.io/badge/LANGUAGE-C%23-239120?logo=csharp&logoColor=white)
[![Latest Release](https://badgen.net/github/tag/Nochala/Betterment_Improvements?label=Version&color=blue)](https://github.com/Nochala/Betterment_Improvements/releases/latest)
[![Last Commit](https://badgen.net/github/last-commit/Nochala/Betterment_Improvements?label=Last%20Commit&color=purple)](https://github.com/Nochala/Betterment_Improvements/commits/main)
![Status](https://badgen.net/badge/Status/WIP/orange)

A big project of mine that's deeply inspired by GTA IV Fusion Fix by ThirteenAG. The goal of this mod is to address Red Dead Redemption II engine limitations and visual issues while also introducing a wide range of gameplay improvements and quality-of-life features. 

---
### Features
- **See the [full feature list wiki](https://github.com/Nochala/Betterment_Improvements/wiki/Full-Feature-List) for all available options.**
- **All features can be individually enabled or disabled through the `INI` fle or the in-game Fusion Fix Settings menu.**
- **Many features replace & overlap other mods, view [Mods Covered in Betterment Improvements](https://github.com/Nochala/Betterment_Improvements/wiki/Mods-Covered-in-Betterment-Improvements) for more details.** 
- **If you prefer another mod's implementation, simply disable the corresponding feature in `BettermentImprovements.ini` file or the in-game settings menu.**
- **Development is still work in progress, some features are experimental.**

### Requirements
- [**Latest ASI loader**](https://github.com/ThirteenAG/Ultimate-ASI-Loader/releases) _**(preferably dinput8.dll)**_
- [**Latest ScriptHookRDR2**](https://www.dev-c.com/rdr2/scripthookrdr2/)
